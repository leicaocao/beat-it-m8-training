# M8 乌拉特克复盘室

`dist/` 是静态网站，部署在已有腾讯云站点的 `/m8-review/`。M8 战术训练台继续使用 `/m8/`。部署时只复制 `dist/`。

## 同步和导入

本机运行 `node m8-review/serve.cjs` 后，打开 `http://127.0.0.1:4194/`，点击「导入日志」，可粘贴 WCL 报告链接或带 `fight=战斗编号` 的战斗链接。服务优先读取已有的本地复盘 JSON；没有对应文件时才使用下方的 WCL 授权即时拉取。支持 `fight=last`（最后一场史诗乌拉特克）。报告数据保留在本机页面，服务不开放给其他电脑。

静态站点和单文件离线版仍可选择 JSON 文件，或用链接打开已随页面载入的报告；它们不会代替本机服务拉取未导入的私有日志。

运行 `node m8-review/sync.cjs WCL报告编号`，使用本机授权读取史诗乌拉特克（3492）战斗。设置 `WCL_SERVER_DIR` 指定授权服务目录，设置 `WCL_REPORT_OWNER_ID` 指定允许同步的 WCL 上传者编号。也可在本地 `data/sync-settings.json` 设置 `serverDir` 和 `reportOwnerId`。导出的复盘 JSON 放在 `data/` 下，通过页面的「导入日志」打开。浏览器在本机读取文件，数据不会提交给托管服务器。

「用 WCL 链接定位」可跳到已导入报告的战斗编号和回放位置。若先粘贴链接，页面会在导入对应报告后定位。右侧事件列表默认显示回放点前后 20 秒，手动滚动会暂停跟随。

公开报告可以按部署需要放在 `dist/data/<报告编号>.json`，并在 `dist/data/catalog.json` 中写入对应的 `code` 和 `title`。私有或未列出的公会报告留在 `data/`，由有权限的成员本地导入。

## 离线复盘和公开样例

在仓库根目录运行以下命令。离线文件生成到 `m8-review/data/本周M8复盘.html`，默认打开第一个报告。

```powershell
node m8-review/sync.cjs LbHw4cjQX9AK7DZ1 4 --public-sample
node m8-review/make-offline.cjs 公会报告编号 m8-review/data/LbHw4cjQX9AK7DZ1-4.json
node m8-review/verify-workspace.cjs --fresh
```

## 数据解释

- 站位来自 WCL 资源事件中的坐标。使用同一地图内的相邻样本进行插值，超过 3 秒的采样缺口不连线。
- 可核对到固定场地锚点时，P1、过场和 P3 使用配准后的场地参考图。P2 以坐标网格显示分房站位。场地边界为示意。
- P1 核对到畸体中心出生点和已知侧边尾巴时，使用 DreamForge 2123×1188 主平台原图。保留原朝向和宽高比，以出生点定中心，平台边缘到中心约 37.8 码，由同场 Hexweaver 回放的玩家与平台位置对照得出，不用蛇身模型推算坐标。玩家、蛋和 NPC 共用同一投影，不移动原始坐标。关闭底图可看 WCL 坐标；其他阶段沿用原有底图和尾巴虚线。疫鳞畸体超过 3 秒无坐标前淡出，新采样到达后淡入；不推算空档轨迹。
- P1 分摊参考圈从已采样的幽魂触手坐标向场内推约 20 码，半径约 10.5 码，依据同场回放中两次分摊的可见范围估算。预览圈不用于判定谁吃到分摊，不改变时间轴或参与记录；可在图层中关闭。
- P1 3D 动画优先读取可选的本机原模型包，按 WCL 施法时刻播放 Boss 和尾巴 GLB 自带的动画。没有模型包时回退到本地简模，关闭「P1 3D 动画」时保留图标。尾巴实际坐标用小点标记。
- 虚影尾巴的腐蚀浪潮以 WCL 施法时间和坐标为起点，按 Hexweaver 同把弹道图校准为扇形散开。传播速度和路径仍是视觉近似，命中只由 WCL 事件决定。月牙波头保持约 5.2 码的固定视觉宽度，毒液纹理及气泡独立流动。本机缺少毒液和泡沫纹理时使用生成纹理；原纹理不进 Git，也不会打进离线包。
- 本机模型包来源于 Hexweaver 的公开回放，放在忽略 Git 的位置，不随网页或离线包发布。用 `npm install --prefix data/model-build-tools --ignore-scripts --save-exact three@0.180.0 esbuild@0.25.10` 安装构建工具，再用 `node build-p1-original.cjs` 从 `data/hexweaver-ulatek.glb` 和 `data/hexweaver-gore-rattle.glb` 生成本机包。`--runtime-only` 只重建加载器，不打包模型。
- 阶段以 WCL 阶段记录为准。P2 分房依据东西守卫位置和持续的玩家采样。P3 咬击点名来自紧随施法的减益记录。
- 携卵条显示记录到的减益时段。地面蛋图标只来自有位置记录的卵簇或硬化蛋，不代表场上全部蛋。蓝条是同一实例的硬化护盾强度扣除硬化吸收事件后的剩余量，不是单位生命值。证据不足时只画蛋图标；已确认破盾时隐藏盾条，图标短暂闪烁，表示破盾提示，不代表仍未被拾取。
